Components

Three small primitives. Appearance belongs to component CSS; fields and constraints remain native HTML. Examples run locally in the browser.

Button

Uses a native button for clicks, keyboard access, and disabled behavior.

Ready. 
<ui-button label="Say hello"></ui-button>
<ui-button label="Disabled" disabled></ui-button>

Card

A plain surface containing your own HTML. No appearance configuration model.

A small container

Compose text, native controls, or other primitives here.

 
<ui-card>
  <h3>A small container</h3>
  <p>Your content</p>
</ui-card>

Form

A thin wrapper around a native form. Required fields use browser validation; submit emits local values without navigation or clearing drafts.

 
Submit to see local values.
<ui-form>
  <form>
    <label>Name <input name="name" required></label>
    <ui-button label="Submit" type="submit"></ui-button>
  </form>
</ui-form>

form.addEventListener("aui-form-submit", event => {
  console.log(event.detail.values);
});
