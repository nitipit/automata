# GNOME Desktop Control

Start with AT-SPI for accessible controls and `ydotool` for keyboard or mouse input
when needed. Prefer a more direct application interface when appropriate.

Discover missing details as needed and reuse working methods from conversation
context. Reusing a method does not establish the current target or focus.

Persist useful setup knowledge only when requested or covered by an explicit
retention policy, using the agreed storage location. Keep live target identities
and focus state out of durable notes.
