Message Router web reference — build and license provenance

The authoring build copies two existing central browser bundles byte-for-byte.
It does not rebuild their dependency graphs. SHA-256 checks recognize the reviewed
cached artifacts, not an independently reproducible dependency build or a legal
audit. HTML and owned modules are reproducible from the authoring tree and those
same bundle inputs. No source maps, dependency source, or ECharts are shipped.

Most dependency notices came from existing exact-version cached packages. Fourteen
missing exact-version notices were retrieved with explicit approval on 2026-09-29
from versioned registry.npmjs.org archives. The notice collection attributes each
retrieved package/version and URL. Archives were bounded, inspected without
extractall or code execution, then removed from private temporary storage. Only
license texts are retained here; no package installation or bundle update occurred.
Adjacent-version license files were not substituted. The web reference build itself
is cached-only and performs no network operations.
